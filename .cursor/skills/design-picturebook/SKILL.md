# design-picturebook（下書き）

## 世界観
- 水彩・絵本風イラストで統一する。写真中心のデザインにしない
- UI/UXサンプル（5画面：ホーム／絵本マップ／建物詳細＋クイズ／人物／さんぽ帳）のデザインシステムを正とする

## ルール
- 色・フォント・余白は src/theme/ のデザイントークンから使う。画面ごとに直値を書かない
- 建物・風景の表現はイラスト素材（assets/illustrations/）を使い、汎用アイコンや写真で置き換えない
- マップ上の道路・市電の描き分け（主要道路は太く、市電は軌道線）は illustrated-map skill のルールに従う
- 新しい画面を作る前に、UI/UXサンプルの同種画面のトーンに合っているか確認する
