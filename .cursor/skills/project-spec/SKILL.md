# project-spec（下書き）

## 決め打ち仕様
- アプリ名「熊大さんぽ」。熊本大学の歴史的建造物・ゆかりの人物を学び探索するアプリ
- Expo + TypeScript + Expo Router、iOS/Android両対応
- バックエンド／配信基盤は Cloudflare。コンテンツ（建物・人物データ、イラスト）は Cloudflare から配信し、アプリ更新なしで差し替え・追加できる構成にする
- アカウント登録・ログインは不要。個人データ（お気に入り、訪問スタンプ）は端末内保存
- デザインは絵本風イラストで世界観を作る。写真中心にしない
- 配布は限定配布（知り合い・学内）。EAS内部配布が本命

## 画面構成（UI/UXサンプルが土台）
ホーム／絵本マップ／建物詳細（＋クイズ）／人物／さんぽ帳 の5画面

## コンテンツの範囲
- 文化財指定の建造物6件：五高記念館、化学実験場、表門（赤門）、工学部研究資料館（重要文化財）、熊本大学本部、山崎記念館（登録有形文化財）
- 非指定の歴史的建造物、ゆかりの人物も含む

## やってはいけないこと
- 座標・史実の創作（不明なものは「未確認」とする）
- アカウント機能の追加
- 推定位置（山崎記念館など）を確定情報として扱うこと
