# illustrated-map（下書き）

## 基本方針
- マップは実際に機能するものにする（ズーム／スクロール、ピン、現在地、タップで詳細、絞り込み）
- ピンの位置と案内は座標データ側で正確に持つ。イラストは座標に紐づく「皮」であり、イラストの見た目に合わせてピンを動かさない
- 座標の正は data/geo/spots.csv。値が無いスポットは創作せず、未取得として扱う

## 敷地境界ルール（2026-11-26確定）
- 敷地内外は長方形ではなく周囲の道路で区切る
- 緑の敷地枠は黄色い主要道路を越えず、道路の中心線データから少し内側に引く（直線で近似せず中心線の実形状に沿わせる）
- 本荘は産業道路を跨ぐ3地区構成（北＝白川南岸〜産業道路／中＝産業道路の南・本荘2丁目／南＝九品寺4丁目）
- 白川のラベルは川の北西側の流れの上に置く
- 白い細い道は主要道路でなくても現地で重要なので、敷地内外を問わず描く
- 主要道路（産業道路、銀座橋通りなど）と熊本市電の軌道は地図上で判別できるように描き分ける

## 確定済み素材
- 本荘の下敷き確定版：data/geo/honjo-campus-underlay-v7.png
- 大江の下敷き確定版：data/geo/ooe-campus-underlay-v8.png
- 黒髪北・黒髪南の下敷きと4区画のイラスト試作も data/geo/ と assets/illustrations/ に格納

## 注意点
- 山崎記念館は建物形状がOSMに無く、位置は推定（32.7953, 130.7108）。座標は変えない。ピン表示時は推定であることが分かる扱いにする
- 表門（赤門）は 32.814398, 130.726565（文化遺産オンライン、OSMと照合）。黒髪北のイラスト範囲に入るので、そこへピンを置く
- 文書館は座標未確定。ピンを置かない
- ピンの絞り込みは文化財指定（`data/geo/categories.json` の重要文化財／登録有形文化財／なし）。キャンパスは地図の切り替えで選ぶ
- 地理データの出典は OpenStreetMap（ODbL）。クレジットは外さない。常時表示は `© OpenStreetMap contributors` の1行とし、ODbL の説明はシートに置く（文言の正は `docs/ui-redesign.md`）
