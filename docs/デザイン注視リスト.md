# デザイン注視リスト

方針（2026-11-27）：「このアプリだからこそ、できる・知れる・体験できる」を前面に出す。
スタンプとバッジはアプリの顔でありコレクションの核なので、既成アイコンではなくオリジナルデザインに注力する。

## A. スタンプ（最注力）
コレクションの中心。駅スタンプや御朱印のように「その場所でしか押せない」一点物にする。

| 対象 | 数 | デザインの方向性 |
|---|---|---|
| 建物スタンプ | 8（建物ごと） | 各建物の特徴的な形（塔・屋根・門のシルエット）を主役に、建物名を組み合わせた印。少し掠れた押し味でアナログ感を出す |
| 区画制覇スタンプ | 4（黒髪北・黒髪南・本荘・大江） | 建物スタンプより一回り大きく豪華に。区画を象徴する風景（白川、市電、グラウンド等）を描く |
| 全制覇スタンプ | 1 | 特別仕様。さんぽ帳の最後のページに押される |

ルール：線の太さ・書体を全スタンプで統一し、並べたときに「同じ帳面の印」に見えること。モノクロ1色で成立させる（色はインク色のみ）。
原画がある建物は `assets/stamps/<建物id>-stamp-vermilion.svg` をレジストリに載せると差し替わる。無い建物と区画制覇・全制覇は自作の駅スタンプ型のまま。

### 色と枠（2026-11-27確定）
- 通常の建物スタンプは全区画とも朱色に統一する（区画ごとに色は変えない）
- 区画の区別は枠の形で付ける（JR東日本のフレーム分類に倣う）：黒髪北＝丸、黒髪南＝四つ丸輪、本荘＝八角形、大江＝六角形
- 区画制覇スタンプは紫紺、全制覇スタンプはうこん×紫紺（熊本大学公式カラー）
- アプリ現行の「全部煉瓦色」は朱色への置き換え対象

### 押印ルール（2026-11-27確定）
- スタンプは現地限定：スポットの座標から半径約100m以内でのみ押せる
- 開発中の位置テストには、既にある開発用位置切替を使う。これは開発ビルド限定の正式機能として残し、公開ビルドには出さない

## B. バッジ（注力）
達成の証。スタンプとは別系統の見た目（金属・刺繍ワッペン風など）にし、集める楽しさを分ける。

| バッジ | 条件の例 | モチーフの方向性 |
|---|---|---|
| はじめの一歩 | 初スタンプ | 赤門 |
| 黒髪マスター／本荘マスター等 | 区画の全建物訪問 | 区画の象徴建物 |
| クイズ博士 | クイズ全問正解 | フクロウ、または五高の帽子 |
| 人物通 | 人物全員分の詳細を読了 | 万年筆・本 |
| 朝のさんぽ／夕方のさんぽ | 時間帯の訪問 | 朝日・夕日と建物 |
| 完全制覇 | スタンプ全種 | 熊本大学の正門と銀杏並木のような集大成の絵柄 |

ルール：形（円／盾／六角など）と縁の装飾を統一し、中の絵柄だけ変える。未取得はシルエット表示で「何かある」ことだけ見せる。

## C. 人物の顔（注力）
現在は漢字1文字の丸アイコン。相関図の主役になるため、格上げの候補。
- 絵本風の似顔絵イラスト（写真のない人物も多いので、服装・持ち物・髭などの特徴で描き分ける）
- 相関図のノードも同じ似顔絵を使い、線の色で関係の種類（師弟／同僚／同時代）を分ける
- 似顔絵が難しい人物は、ゆかりの品（著書、柔道着、実験器具など）のアイコンに置き換える選択肢も残す

## D. 地図まわりの顔
| 対象 | 方向性 |
|---|---|
| ピン | 建物の形をしたピン、訪問済みはスタンプ色＋印の模様。色だけでなく形でも状態を区別 |
| 現在地マーカー | 自分を示す小さなキャラクター（帽子をかぶった散歩者など）。コンパスの向きで体の向きが変わる |
| クラスタ | 数字の丸ではなく、束ねたピンの絵柄 |
| 区画切替・凡例 | 紙とインクの世界観を崩さないチップと凡例 |

## E. アプリ全体の顔
| 対象 | 方向性 |
|---|---|
| アプリアイコン | 赤門＋イラストマップの色面。一目でこのアプリと分かること |
| 起動画面（スプラッシュ） | 絵本の表紙を開くような1枚絵 |
| 共有画像のテンプレート | さんぽ帳を画像化するときの額縁・署名まわり |
| 完了・お祝い画面 | 全制覇やバッジ取得時の画面全体の演出（紙吹雪ではなく、印が増える・ページがめくれる等の世界観に合う動き） |
| 空状態・読み込み | お気に入り0件、通信待ちなどに出る小さな挿絵と一文 |

## F. 細部だが世界観を決めるもの
- クイズの星（現在の星形を、建物や葉のモチーフにした評価マークにできるか検討）
- 年代スライダーのつまみと時代ラベル（年号の書体・時代ごとの色）
- タブバーのアイコン（既成シンボルから、地図・クイズ・人物・帳面の描き下ろしへ）
- フォントと数字の扱い（年号・年代の見せ方は人物年表と年代スライダーで統一）

## 進め方
1. まずスタンプ8種＋制覇印のデザイン案を試作し、様式（線・色・書体）を確定する
2. 様式が決まったらバッジとピンの絵柄に展開する
3. 確定した素材はアセットとしてリポジトリに入れ、Cursorが画面に組み込む
