# 熊本大学 歴史的建造物アプリ — 決め打ち仕様（2026-11-25時点）

## アプリ名
- **熊大さんぽ**（2026-11-25 池上決定）
- リポジトリ名の候補：kumadai-sanpo

## コンセプト
- 熊本大学内の歴史的建造物について学べるアプリ
- 建物について知る、熊本大学にゆかりのある人物を知る、アプリ一つで探索できる
- デザインは**絵本風イラスト**で世界観を作る（2026-11-25 池上確認済み）。写真中心にはしない

## プラットフォーム・技術
- iOS / Android 両対応
- Expo + TypeScript
- バックエンド／配信基盤：Cloudflare
- アカウント登録・ログインは不要

## データの扱い（解釈・要最終確認）
- 「クラウド同期」は、アカウント不要と両立する形として、建物データ・人物データ・イラスト等のコンテンツを Cloudflare 側から配信し、アプリ更新なしで差し替え・追加できる構成と解釈している
- ユーザー個人のデータ（お気に入り、訪問スタンプ等）は端末内保存を基本とする

## マップ要件（2026-11-25 池上指定）
- マップは Tokyo Disney Resort App のマップのように、実際に機能するマップにする（眺めるだけの絵にしない）
- 想定機能：ズーム／スクロール、建物のピン、現在地表示、タップで建物詳細へ、カテゴリ絞り込み等
- ただし見た目は、実際の風景を絵で表現するように、絵本風イラストで描く（実在の建物配置・風景をイラスト化したカスタムマップ）

## マップのデータ基盤（2026-11-25 取得開始）
- イラストは実データに基づく。OpenStreetMap（ODbL）の建物形状・座標・道路データを取得済み：~/workspace/projects/kumamoto-heritage-app/data/osm-kumamoto-univ.json、スポット座標は同フォルダの spots.csv
- 座標確定：五高記念館、化学実験場、工学部研究資料館、熊本大学本部（事務局）
- 未取得（公式キャンパスマップ／現地確認で補完が必要）：表門（赤門）、文書館
- 本荘北地区：初回の下敷き・イラストは「不正解」と池上が指摘（2026-11-25）。v2でも白川の位置がズレていると指摘あり（白川はもっと北西側で、北から西へ流れる）。OSMの白川本流データで範囲を取り直し、下敷きv3（honjo-kita-underlay-v3.png）を作成。山崎記念館は推定位置（32.7963, 130.7106）にマーカー。主要道路の描き分け（幹線＝太い橙色、市電＝濃い軌道線）を入れた下敷きv5を作成し、池上が承認（2026-11-25）。その後、本荘の絵本風イラスト試作を作成・提示済み（2026-11-25 16:12）。山崎記念館の位置は推定のまま
- 大江地区は位置が確定（2026-11-25夜、住所・座標の2系統で照合）：熊本大学大江キャンパス（薬学部）〒862-0973 熊本市中央区大江本町5-1。ジオコード 32.7945236, 130.7208275、薬用資源エコフロンティアセンター（薬用植物園）32.795167, 130.722528（Wikipedia記載、2点は約143m）。大学公式アクセス案内でも大江キャンパス＝薬学部・大江本町5-1、市電「味噌天神前」から徒歩5分。公式キャンパスマップ（official-ooe.jpg）の配置：薬学部本館（01番の長い建物）が北側の中心、南の公共道路を挟んで19番の運動場と20番の薬用植物園。座標は池上が2026-11-25に確定：熊本大学 大江地区（大江本町5番1号、世界測地系）＝北緯32.7947203度、東経130.7208876度。先のジオコード（32.7945付近）は正しかった。アシスタントのスクリーンショット解釈（約32.802）は誤り。この座標を中心に下敷きv3（ooe-underlay-v3.png）を作成。市電は北東方向に伸びる。下敷きv4（ooe-underlay-v4.png）と絵本風イラスト試作を作成・提示済み（2026-11-26 07:15 JST）。これで黒髪北・黒髪南・本荘・大江の4区画のイラスト試作が揃った。池上の確認待ちで、合っていれば次はリポジトリ作成
- 黒髪北の下敷きマップ（kurokami-north-underlay.png）と絵本風イラスト試作を作成し、2026-11-25に池上が方向性を承認（「とってもいいですね」）。ピンの位置・案内は座標データで正確に持ち、イラストは上に被せる皮とする方針
- 主要道路の判別（2026-11-25、池上の要望）：産業道路・銀座橋通りなど主要な道路と熊本市電の軌道は、地図上で分かるように描く。下敷きでは幹線道路を太い橙色、市電を濃い軌道線で描き分け、道路名ラベルを付ける（honjo-kita-underlay-v5.png）
- 表示範囲の方針（2026-11-26、池上の指示）：本荘・大江のマップ表示は、キャンパスと周辺の道路を強調し、敷地外は描かない（薄く落とす）。キャンパス中心の下敷き（honjo-campus-underlay.png / ooe-campus-underlay.png）とイラスト試作を作成済み

## マップの敷地境界ルール（2026-11-26確定）
- 敷地の内外は長方形ではなく、周囲の道路（黄色の主要道路）で区切る。緑の敷地枠は黄色い道路を越えず、道路の中心線から少し内側に引く
- 本荘は産業道路を跨ぐ3地区構成：北地区（白川南岸〜産業道路、病院・医学部医学科）、中地区（産業道路の南、本荘2丁目、発生医学研究所等）、南地区（九品寺4丁目、医学部保健学科）
- 白川のラベルは川の北西側の流れの上に置く
- 産業道路は東へ行くほど北へ上がる斜めの道。枠は中心線の実データに沿わせる
- 本荘の下敷き確定版：data/honjo-campus-underlay-v7.png（2026-11-26 ユーザー承認）
- 大江の下敷き確定版：data/ooe-campus-underlay-v8.png（2026-11-26 ユーザー承認）。北側の区画は白い構内道路より北西の住宅地を含めない。北側の枠は南の黄色い公共道路の中心線データに沿って、その手前まで伸ばす
- 白い細い道は主要道路でなくても現地で重要なので、敷地内外を問わず描く
