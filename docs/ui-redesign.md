## 0. 要約

- 「AIっぽさ」の正体は、(a) どの画面も同じ形(角丸カード+細い枠線+見出し+説明文)、(b) 画面ごとに説明文が積まれている、(c) 標準のヘッダー・戻る・確認ダイアログを手作りしている、(d) 色が「クリーム地+テラコッタ」というAI生成物の典型配色、の4つ。
- 文字の量は、リード文・注意書き・空状態の文を合わせて、画面を開くたびに約 600〜900 字が出る。「この端末だけに保存」という趣旨の文は 5 画面で 16 回出る。「位置は推定です…」は 8 箇所(同じ文)。
- 方針: **地図のイラストを主役にして、それ以外のUIは静かにする**(skillの「大胆さは1か所に使う」)。文章はアイコン・色・状態・直接操作に置き換え、出典・注意・長文はタップの先(シート)へ送る。事実と出典は消さない。
- 使うskillは `expo/skills` の `expo-design-system`(AIっぽさ20項目のチェック表つき)・`expo-native-ui`・`expo-animation`。文章とデザイン判断には Anthropic の `frontend-design` を併用。

### 2.2 そのほか「AIっぽい」症状

1. **アイコンがゼロ**。タブ以外に SF Symbols/Material の記号がなく、ボタンは全部「文字+角丸」(「クイズを始める」「説明を見る」「訪問した」「スタンプを消す」「お気に入りに入れる」「マップで見る」「この建物を見る」「閉じる」)。
2. **同じボタンが縦に積まれる**。クイズ一覧の1建物あたり、主ボタン(塗り)+副ボタン(枠)の2つ。ノートの1建物あたり、リンク+未押印バッジ+「訪問した」+「お気に入りに入れる」の4つ。8建物分が縦に並び、ほぼスクロールするだけの画面。
3. **ホームタブ(`app/(tabs)/index.tsx`)は“説明文+他の4画面へのリンクカード”**。下のタブと同じ移動先を重複して出すだけ。
4. **地図が一番の主役なのに、上部を3段の操作列が占める**(`CampusSwitcher` の4つの文字ボタン、`CategoryFilter` の3つの文字チップ、開発用トグル、位置バナー)。実機の縦の約 1/4。
5. **ピンが無個性な丸**(`MapPin.tsx` 色付きの円+「推定」の文字ラベル)。絵本の絵に対して汎用的。
6. **建物・人物に“絵”が無い**。一覧も詳細も文字だけ。地図のイラストという最強の素材が地図タブ以外で使われていない。
7. **見出しの階層が1種類**(`title 28 / body 16 / caption 13` の3段。セクション見出しは緑の太字)。どの画面も同じ見た目。
8. **文末が全部「です・ます」の説明調**で、操作ではなく説明をしている(例: 「現地にいなくても解けて、成績はこの端末だけに残ります。」)。
9. **「未確認」「いまの内容にありません」のような内部事情の文**がUIに出る(`PersonDetail.tsx` L18-24・66-67・131-134、`RelatedPeople.tsx` L22-25、`BuildingDetail.tsx` L21・28)。
10. **選択の結果が文字で出る**。クイズの正誤は「正解/不正解」の文字+色。アイコン・haptics・動きが無い。
11. **haptics なし・動き無し**(Reanimated は地図のズームのみ)。押した実感が色の変化だけ。

## 3. 刷新計画

### 3.1 方針(エンジニアの3大美徳に対応づけ)

| 美徳 | 意味 | 具体策 |
|---|---|---|
| 怠惰(Laziness) | ユーザーの手数を最小に | ホームタブ廃止 / 起動直後に地図(最後に見たキャンパス、位置許可済みなら今いるキャンパスを自動で開く)/ スタンプ1タップ・確認ダイアログ無し(「取り消す」を数秒出す)/ クイズは選んだ瞬間に判定、正解なら自動で次へ / 一覧からタップ1回でクイズ開始(「始める」ボタンを無くす)/ フィルターは凡例をタップするだけ |
| 短気(Impatience) | 即フィードバック | 押下100ms以内に見た目が変わる / 重要操作は haptics(視覚と同じフレーム)/ 読み込み文を出さない(スケルトンか何も出さない。端末内データは同期的に表示)/ 画像は expo-image の placeholder(blurhash)/ 画面遷移はネイティブ標準 |
| 傲慢(Hubris) | 誇れる作り込み | ピン・スタンプ・アイコンを絵本の世界観で作り込む / 地図のイラストを全画面で再利用 / トークンと部品を1か所に / 作ったら実機で「指でなぞって」確認(下記の完了チェック)|

### 3.2 見た目の方向性: 「絵本の地図帳を、そっと閉じたノートで持ち歩く」

**主役は地図のイラスト。UI の枠はOSの標準(ヘッダー・タブ・シート)に任せ、独自の飾りを減らす。** 独自の色・書体・動きは「ピン」「スタンプ」「見出し」の3点だけに使う。

#### 配色(イラストから抽出して決める)
4枚のイラスト(黒髪北・黒髪南・本荘・大江)を量子化・ピクセル平均した結果、共通して出る色は次のとおり。

| 役割 | 値 | 根拠 |
|---|---|---|
| 紙(地図の余白) | `#F6F3E7` | 4枚の余白色(`#F8F6EB` `#F7F4E8` `#FBF6EB` `#FCFAF6`)の平均的な値 |
| 道・土 | `#D3C0A3` | 地図の道路の色 |
| 若葉(芝・木) | `#96AC62` / 濃 `#46601E` | 緑の領域の平均/暗部 |
| 煉瓦(文化財の建物) | `#A25437`(暗)〜`#C07556`(明) | 地図で重要文化財の煉瓦造が赤茶で塗られている。ピクセル平均 |
| 墨(文字) | `#2E2A24` | 線画の暗い茶。紙に対して 12.8:1 |
 
- コントラスト実測(WCAG): 白 on 煉瓦`#A25437` = 5.44、煉瓦`#A25437` on 紙`#F6F3E7` = 4.9、濃緑`#46601E` on 紙 = 6.4、墨 on 紙 = 12.8、**現行の `#C46A45` on `#FFF9F0` = 3.65(小さい文字には不足)**。
- 現行のトークンは近い値を既に使っているので、「**配色を全面的に変える**」より「**使い方を変える**」が肝心: 画面の背景をすべて紙にして枠と影で区切るのをやめ、**画面の背景は白〜ごく薄い紙色の1色、区切りは余白、色は意味を持つ場所(ピン・状態・主操作)だけ**に使う。
- **色に意味を持たせる**(=文字を減らす手段): 煉瓦=重要文化財、若葉=登録有形文化財、道の色=指定なし。凡例=フィルター(後述)。
- ダークモードは v1 では対応しない(`app.json` は light 固定のまま)。判断事項に載せる。

#### 書体
- 本文: **システム書体(ヒラギノ角ゴ/ Noto Sans CJK)**。Dynamic Type に追従(上限を付けない)。
- 見出し(建物名・人物名・画面の大見出しだけ): **Zen Maru Gothic Bold**(丸ゴシック、OFL、`@expo-google-fonts/zen-maru-gothic` 0.4.2)を候補とする。frontend-design が「クリーム地+セリフ体の見出し」を“AIの典型”と名指ししているため、明朝は避ける。
- 注意: 日本語フォントは重い。npm の展開サイズは `zen-maru-gothic` 約19MB・`klee-one` 約16MB(全ウェイト入り)。**Boldの1ファイルだけ**を `expo-font` で読み込む。サイズと起動時間は実機で確認が必要。
- 文字サイズは「タイトル / 本文 / 補足」の3段+太さと色で階層(vercelの react-native styling 規則もこの方針)。文字の“大きさ”を増やして階層を作らない。

#### アイコン
- 操作用: **SF Symbols(iOS)/ Material(Android)**を `expo-symbols` で一貫して使う(`expo-native-ui` の規則)。一覧: `heart` / `heart.fill`、`location` / `location.fill` / `location.slash`、`checkmark` / `xmark`、`info.circle`、`link`、`chevron.right`、`questionmark`、`map`、`person.2`、`book.closed`。絵文字は使わない。
- 絵(建物・人物の代わりになるもの): 汎用アイコンを置かず、**地図イラストをピンの位置で切り抜いた“挿絵”**を使う(下記)。これは `design-picturebook` skill の「建物は汎用アイコンで置き換えない」にも合う。新しい画像素材は不要。
- 印鑑(スタンプ)は **View で描く**(丸+建物名の頭の1字、煉瓦色、少し傾ける)。

#### 動きと haptics(`expo-animation` の頻度ゲートに従う)
| 場面 | 頻度 | 判断 |
|---|---|---|
| タブ切替・一覧スクロール・フィルター切替 | 非常に多い | **動かさない**(標準のまま) |
| ボタン押下 | 多い | 150ms以下の色/不透明度の変化のみ。全幅の行は背景ハイライト、小さいボタンだけ軽く縮む。Squish Reflex を避ける |
| ピンの選択 | 多い | バネ(短い)で軽く跳ねる+ `selectionAsync` |
| ピンタップで下から出るプレビュー | 時々 | 標準シート/バネ。スワイプで閉じる |
| クイズの正解/不正解 | 時々 | 選択肢の色+アイコン+ `notificationAsync(Success / Error)`(視覚と同時)。正解は 0.8〜1.2 秒で自動送り |
| **スタンプを押す** | **まれ(最初の1回は特別)** | ここだけ“喜び”の予算を使う: 大きく現れて落ち着く(バネ)+ `impactAsync(Medium)` + `notificationAsync(Success)`。全部集めたときだけ少し長く |
| お気に入り(ハート) | 時々 | アイコン切替+ `selectionAsync`。アニメは出さない |
| 画面の入場 | — | **付けない**(Grand Entrance 回避)。Reduce Motion を尊重 |

haptics は iOS のみ・常にビジュアルと併用(音・振動が切られている人にも伝わる)。`expo-haptics ~58.0.8` を依存に追加(現在は未導入)。

### 3.3 画面ごとの変更

共通ルール(`expo-native-ui` / `expo-design-system`):
- 画面の大見出しは **スタック/タブのネイティブヘッダー**(大見出し折りたたみ・スワイプで戻る)。自前の「戻る」「一覧へ」テキストボタンは廃止。
- `ScreenLink`(カード型リンク)と `PlaceholderScreen` は廃止。リンクは行全体のタップか、アイコンボタン。
- 枠線(hairline)は一覧の区切り線だけに限定。カードは「サムネイルを含む1行(行内ハイライト)」にして、箱で囲まない(Everything's a Card 対策)。
- 余白は3段階で意味を持たせる: 行内 < グループ間 < セクション間(16固定をやめる)。
- 色・サイズ・余白の直値は `src/theme/` に集約(既存の `tokens.ts` を拡張。**第2のテーマは作らない**)。

#### (a) タブ構成
- 現在: ホーム / マップ / 建物 / 人物 / さんぽ帳(5つ)。
- 提案: **地図 / クイズ / 人物 / さんぽ帳(4つ)**。ホームは廃止(中身は説明文とリンクだけ)。起動時は地図。「建物」タブは中身がクイズなのでラベルを「クイズ」にする。
- ラベルは1語。アイコンは `map` / `questionmark.bubble` / `person.2` / `book.closed`。

#### (b) 地図
- **全面表示**(ステータスバーの下まで。上部の操作列を無くす)。
- キャンパス切替(4つの文字ボタン)→ 左上に**現在のキャンパス名だけの小さなガラスのピル**(`expo-glass-effect` または標準メニュー)。タップで4つのメニュー。**横スワイプでも隣のキャンパスへ**。最後に見たキャンパスを覚える(端末内)。
- 絞り込みの文字チップ3つ → **凡例の色ドット3つ(煉瓦/若葉/道色)をそのまま切替ボタンに**。タップでON/OFF、選択中のみ濃く。文字は付けない(長押しで名称、アクセシビリティラベルには名称を残す)。
- 現在地バナー(文章+ボタン2つ)→ **右下の丸い「現在地」ボタン1つ**。状態はアイコンで表す: `location`(未取得)/ `location.fill`(取得)/ `location.slash`(拒否・オフ。タップで設定を開く)。許可の説明は iOS の許可ダイアログ(`app.json` の `locationWhenInUsePermission`)に任せ、アプリ側の長文は出さない。学外のときはボタンが淡色になり、押すと1行のトースト(「学外です」など10字以内、数秒)。
- ピンのタップ → 現在の吹き出し(文章+ボタン2つ)を廃止し、**下から出る小さなプレビュー**: 切り抜きの挿絵+建物名(1行)+区分の色ドット。**そのプレビュー全体がタップ領域**で、詳細へ進む。下にスワイプで閉じる。「この建物を見る」「閉じる」の文字ボタンは無し。
- 「推定」(山崎記念館): ピンの**破線の輪**+プレビューに小さな「推定」チップ1つ。8箇所の同文を廃止。(AGENTSの「確定値として表示しない」は、破線+チップで満たす。→判断事項)
- ピンの見た目: 丸 → **小さな屋根形のピン(煉瓦色)**。選択中は大きく・濃く。
- OSMクレジット: 常時表示は残すが `© OpenStreetMap contributors` の1行・小さい文字に短縮(「地図データの出典:」「(ODbL)」は“ⓘ”のシートに移す)。→判断事項
- 空状態(「この区分の地点は、この地図にはありません。」)→ 文章をやめ、全ドットがOFFのときはピンが薄く出る程度にし、ドットをタップすればすぐ戻せる。

#### (c) クイズ(旧「建物」タブ)
- 一覧: 見出し+リード文(65字)を廃止。**サムネイル(挿絵)+建物名+3つのピップ(○○○ 成績)**だけの行。キャンパスごとにセクション見出し(1語)。行全体をタップすると**そのままクイズ開始**。「説明を見る」リンクは行の長押し/右端の `info.circle`。成績の文(「クリア済み · 最高2/3 · 最終 …」)は廃止し、ピップ(塗り=正解)とクリア済みの印鑑のみ。
- 出題: 画面上部に3つのドットで進行、質問文を大きく、**選択肢は大きなタイル4つ**(タップ領域 44pt以上)。選んだ瞬間にタイルが色変化+`checkmark`/`xmark`+haptics。「正解です/不正解です」の文字は廃止。
  - 正解: 0.8〜1.2秒後に自動で次へ(`ⓘ` を押している間は止まる)。
  - 不正解: 正解のタイルを光らせ、解説を**下のシートに1〜2行のプレビュー**として出し、タップで全文。次へはスワイプ/タップ。
  - 出典は解説シートの「出典」アイコン(`link`)の先に移す。事実と出典は消えない。
  - 解説文は平均79字・最大118字と短いので、全文を出しても 4 行程度。長くしない運用を維持。
- 結果: 「クリアしました。3問中2問以上でクリアです。何度でもやり直せます。以前のクリアは…最高点は…」(約90字)→ **3ピップ+クリアなら印鑑のアニメ**+丸い「もう一度」ボタン(`arrow.clockwise`)。条件(2問以上)は、3つのうち2つ目にだけ小さな線を引いて表すか、省略(初回のみ短いヒント1行でも可。→判断事項)。
- 位置の注意文 → 廃止(推定チップのみ)。

#### (d) 人物
- 一覧: リード文(85字)を廃止。**「頭文字の印(姓の1字を煉瓦色の印鑑風の円)+名前+役割(1行・短く)」の行**。区切りは余白とhairline。ゆかりの学校(五高/高工/医学/藩校/設計者など)でセクションに分ければ、色や文字を足さずに構造が出る。肖像は載せない(決定済み)。別名は一覧では出さない(詳細だけ)。
- 詳細(ネイティブのスタック詳細):
  - 大見出し=名前(見出し書体)、その下に読みを小さく。
  - **「生没年」の文 → 年表バー**: 左右に生年・没年の数字、五高などに在籍した期間をバー上でハイライト(1本の線)。「未確認」は“?”の記号(アクセシビリティラベルは「未確認」)で出し、文章にしない。
  - 学校との関わり(役割・期間・前身)→ 1行のチップ(例:「五高 英語教師 1896–1903」)。
  - 要約(平均84字)→ 2行で省略+「続き」で展開(progressive disclosure)。エピソード(3件×約90字)→ 1件目だけ2行表示、残りは「もっと見る」で展開。
  - 関係する建物 → **挿絵つきの横スクロール**(タップで建物詳細へ)。
  - 出典 → 末尾の小さな `link` 「出典 3」→ シート。
  - ハート(お気に入り)はヘッダー右上のアイコン1つ。

#### (e) 建物詳細
- 上部に**ピンの周辺を切り抜いた挿絵(大)**。タイトルは見出し書体。区分は色ドット+短いラベル。
- 事実は**アイコン付きの行**: `calendar` 竣工年(「1889」)/ `clock` 見学(「毎週火曜休館」など、短い要約。全文はタップで展開)/ `yensign` 入館無料 など。長い見学案内(最大112字)と要約(117〜201字)は2行で省略+「続き」。
- 関連人物 → 横スクロールの人物の印(タップで人物詳細)。
- 下部に**親指で押せる操作バー**: **スタンプ(主操作・大)** / ハート / 地図で見る(`map`)。ヘッダーのタイトルはスクロールで小さくなる標準挙動。
- 出典 → `link` 「出典 N」でシート。未確認の項目は“?”の記号か、行ごと隠す(データ側の「未確認」はそのまま)。
- 「位置は推定」→ 挿絵上の破線ピン+チップ。

#### (f) さんぽ帳
- **スタンプラリー帳として再設計**: 上部は進行リング(「3 / 8」の数字だけ)、その下に**8つの“スタンプ枠”のグリッド**(2列)。未押印は挿絵が薄く・破線の枠、押印済みは挿絵がフルカラー+印鑑+日付(小さく)。
- お気に入りは別セクションを2つ設けず、**ハートの絞り込みトグル**(ヘッダーのアイコン)で切り替える(建物と人物の両方を横に並べる、または2つのタブ=セグメント)。
- リード文2つ(130字)、「8件中0件に…」「まだありません…」を廃止。空状態は**破線の空枠**で「次にやること」を示すだけ。
- 「この端末だけに保存」の説明は**ヘッダーの `info.circle` → シート1か所だけ**にまとめ(「アカウントなし/サーバーへは送らない/位置は保存しない/機種変更では移らない」の4点を1か所に)。他の画面(クイズ・詳細・記録操作)の同趣旨の文は全部削除。個人データを端末内に限る方針は変えない。
- スタンプの取り消し: 長押し → 取り消し(または押印済みの印をもう一度タップ)。**確認ダイアログは出さず、数秒間「取り消す」を出す**(アンドゥ)。お気に入りも同じ。
- 読み込み中の文は出さない(端末内ストレージの読み込みが済むまで枠のみ薄く表示)。

### 3.4 文字を減らすルール(コードエージェントへの指示にそのまま使える)

1. 画面のタイトルは1つだけ(ネイティブヘッダー)。**リード文・説明文を置かない**。
2. ボタン・ラベルは**1語〜10字**。操作はアイコン中心で、アクセシビリティラベルに文字を持たせる(視覚上の文字は不要)。
3. 本文は**原則2行まで**。それ以上は「続き」で展開。1画面の“折りたたまれていない本文”は**1段落まで**。
4. 出典は**常にタップの先**(`link` 「出典 N」→ シート)。画面ごとに「出典」見出しとリンク列を置かない。
5. 注意書き(推定・端末内保存)は**状態の記号**(破線・チップ・ⓘ)に置き換え、全文は **1か所のシート**にだけ置く。同文を複数画面に置かない。
6. 空状態・エラーは**1行+1つの行動**。状況の説明ではなく、次の一手(例: 「設定を開く」)。内部事情の語(「いまの内容にありません」等)は出さない。
7. 読み込み中は文字を出さない(スケルトン/何も出さない)。
8. 数値・状態は**記号(ピップ・リング・色・印)**で示し、文にしない(「8件中0件に…が付いています」→ 「0 / 8」)。
9. 同じ操作は全画面で**同じ名前・同じアイコン**(スタンプ=印鑑、お気に入り=ハート、地図=`map`)。
10. 事実(竣工年・指定・経歴)と出典は**データから消さない**。見せ方だけ変える。「未確認」は“?”記号+読み上げラベル。

### 3.5 操作のショートカット(怠惰・短気)
- 起動 → 地図(最後のキャンパスを復元。位置許可済みで学内なら自動でそのキャンパス)。
- クイズ一覧 → 行タップで即開始。選択肢タップで即判定。正解は自動送り。
- スタンプ → 詳細の下部バーで1タップ(位置チェックなし。仕様どおり手動)。取り消しは数秒のアンドゥ。
- 地図 → ピンをタップで下からプレビュー、スワイプで閉じる、プレビューをタップで詳細。
- 詳細 → ネイティブのスワイプで戻る。長押しメニュー(スタンプ/お気に入り/地図で見る)は一覧の行に付ける(`@expo/ui` のメニュー or `Link.Menu`、要確認)。
- 任意(iOS 18+): 一覧のサムネイルから詳細への `Link.AppleZoom`(ズーム遷移)。**Expo Go で動くかは未確認**。動かなければ標準の遷移。

### 3.6 プライバシー(変更なし・再確認)
- お気に入り・スタンプ・クイズ成績は端末内のみ(AsyncStorage、idと日時だけ)。サーバーへ送らない。位置は端末内のメモリのみ。
- UIの変更で保存する項目を増やさない。「最後に見たキャンパス」は端末内の1値(個人データではあるが位置ではない)。保存する場合は同じ保存規則に載せる。
- 「この端末だけ」の説明文は1か所に集約するが、**内容を弱めない**(4点: アカウントなし・サーバー送信なし・位置を保存しない・機種変更では移らない)。

### 3.7 実装の進め方(PRの割り方・各PRは develop から feature ブランチ)
1. **基盤**: skill を `.cursor/skills/` へ追加、`tokens.ts` を拡張(色・間隔3段階・書体・半径)、`expo-symbols`・`expo-haptics`・フォントの導入、タブを4つに(ホーム廃止)、スタック詳細をネイティブヘッダーに、`ScreenLink` / `PlaceholderScreen` の撤去、共通部品(`StampSeal`、`MapThumb`、`Pip`、`SourceSheet`、`InfoSheet`、`UndoToast`)。
2. **地図**: 全面表示、キャンパスのピル/スワイプ、凡例フィルター、現在地ボタン、ピン、プレビュー。

### 3.8 完了チェック(各PR共通)
- `native-slop.md` の grep: Touchable 0件 / `Alert.alert` は“元に戻せない操作”以外で0件 / 絵文字0件 / `headerShown:false` はタブのコンテナのみ。

- Dynamic Type 最大でも主操作が押せる。タップ領域 44pt 以上。コントラスト 4.5:1 以上(煉瓦`#A25437`は紙の上で 4.9)。
